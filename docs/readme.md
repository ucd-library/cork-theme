# Cork Theme Docs

Documentation for `@ucd-lib/cork-theme`. All links are relative, and a folder's `readme.md` is its index.

`@ucd-lib/cork-theme` is the UC Davis Library's brand theme for web applications. It's built on the official UC Davis styles, with Library additions on top, and provides:

- **Styles:**
  - The official Sass source.
  - Compiled stylesheets.
  - A Lit `css.js` partial for each Sass partial.
- **Elements and JS Utilities:** A UC Davis-branded Lit web component library.

- [Upgrade Guides](upgrade-guides/readme.md): what apps must change when this package is updated.
- [Upstream Styles Log](upstream-styles-log.md): a record of each official UC Davis style update merged in.
